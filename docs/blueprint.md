# **App Name**: FlowCraft

## Core Features:

- Workflow Designer: Visual drag-and-drop workflow designer with customizable nodes. Use Gemini/Genkit API to generate step/node suggestions from user intent.
- Platform Adaptability: Cross-platform support (web and desktop) with potential for mobile (optional).
- Automation Engine: Backend microservice executes workflow steps (HTTP requests).
- Firebase Authentication: Firebase Auth (email, OAuth, SSO) for multi-device sync.
- Data Storage: Firestore database for workflow definitions, execution logs and user profiles.
- AI-Powered Suggestions: AI tool suggesting workflow steps based on user input.
- Third-party Integrations: Integrate OAuth to allow connecting external services (Github, Google Drive etc.)

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to convey a sense of innovation and clarity.
- Background color: Light grey (#F0F4F7), a desaturated version of the primary color for a clean, modern backdrop.
- Accent color: Warm orange (#F47920) to highlight important actions and interactive elements.
- Font: 'Inter' (sans-serif) for a modern, clean, and readable interface. Suitable for both headings and body text.
- Clean and simple icons that visually represent different workflow actions.
- Intuitive drag-and-drop interface with a clear visual hierarchy.
- Subtle animations for user interactions such as adding and connecting nodes.
